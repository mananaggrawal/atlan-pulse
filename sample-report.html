What this cannot see

  • Token counts are estimates from character length, not a tokeniser run.
  • Duplicate detection is trigram similarity over names and descriptions. It is a hint to go and look, not a verdict.
  • The permissions check reads declared frontmatter. It is not a security scan and cannot see what a skill actually does.
  • Usage depends on local session transcripts, which only the Claude Code CLI writes. The desktop app keeps no readable session history on disk, so on such a machine usage findings are omitted rather than estimated.
  • This reads transcripts and nothing else. Files that look like keys or credentials are never opened, and are not named in any output.
  • This describes one machine. Cross-person duplication and real ownership are not knowable from a solo scan; they become answerable the moment a second person runs it.
