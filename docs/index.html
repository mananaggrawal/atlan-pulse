Why this exists

You keep adding skills. You never remove any.

Pulse tells you which ones still earn their place.

What it checks

Eight things, checked automatically.

Never invoked

Installed. Never once used.

Concentration

Which few skills do most of the work.

Context budget

What each skill costs you, every request.

Stale

Untouched for months, still loaded daily.

No owner

Nobody listed. Nobody to fix it.

Likely duplicates

Two skills doing the same job.

Broad permissions

Shell or network access it never uses.

Oversized descriptions

Past the 1,536-character limit.

How it works

Three steps.

01

Run it

Reads your skills and your session history. Nothing leaves your machine.

02

Read the report

A summary, a ranked list of what to fix, and a report you can send on.

03

Pack the good ones

Bundle what's worth keeping. One line to install it elsewhere.
